# Public Source Release

This repository is the sanitized, clean-history public source distribution of
Yive. It is maintained separately from the private development repository.

- Source snapshot: `4da90d03f3463cd8a7ed9e4386311b8f812178c3`
- Status: synchronized public source candidate
- License: Business Source License 1.1; see `LICENSE.BSL`

Public changes must continue to exclude private deployment defaults, personal
domains, credentials, runtime state, and generated application packages. Follow
the release checklist under `docs/` before publishing updates.

Public-only governance, licensing, contribution, security, and release files
are maintained in this repository. Neutral Relay examples intentionally do not
inherit private deployment defaults.
